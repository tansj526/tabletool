# 表格工具箱测试博客

这是一篇测试文章，用来验证博客模块是否可以从 `blog/zh` 目录读取 Markdown 文件并自动生成页面。

## 支持能力

- 构建时读取 Markdown 文件
- 自动解析 frontmatter
- 生成博客列表页
- 生成博客详情页
- 支持多语言 SEO

## 示例表格

| 格式 | 用途 |
| --- | --- |
| JSON | 数据交换 |
| CSV | 表格导入导出 |
| Markdown | 文档写作 |

访问博客详情页后，页面会带有独立的 title、description 和 keywords。
