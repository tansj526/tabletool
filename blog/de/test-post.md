# TableTool Testbeitrag

Dieser Beitrag prueft, ob das Blogmodul Markdown-Dateien aus `blog/de` liest und statische Seiten erzeugt.

## Funktionen

- Liest Markdown beim Build
- Analysiert Frontmatter
- Erzeugt eine Bloguebersicht
- Erzeugt Detailseiten
- Unterstuetzt mehrsprachige SEO

| Format | Nutzung |
| --- | --- |
| JSON | Datenaustausch |
| CSV | Import und Export |
| Markdown | Dokumentation |
